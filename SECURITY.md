# Segurança

Este repositório publica documentação estática. Não envie informações privadas, tokens, credenciais, logs de jogadores ou dados pessoais por issue ou pull request.

Para reportar uma vulnerabilidade, use **Report a vulnerability** na página **Security** do GitHub caso a opção esteja disponível. Se não estiver, entre em contato com o responsável pelo repositório por um canal privado; não publique detalhes exploráveis em uma issue. Erros comuns de texto ou de regras podem ser relatados publicamente, sem incluir dados privados.
